# Schools of the Future (2075)

A React + Tailwind website project for a "School of the Future" concept set in **2075**.

## Project Overview

This site presents:
- A future education model in 2075
- Detailed curriculum design (foundations + specialization pathways)
- Pedagogy and assessment model
- Campus architecture concept
- Accessibility and inclusion strategy
- Funding breakdown and school type
- Politics, implementation timeline, and day-in-the-life experience
- Location set to **New York City, New York**

## Tech Stack

- React (Vite)
- Tailwind CSS
- JavaScript (ESM)

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview production build

```bash
npm run preview
```
